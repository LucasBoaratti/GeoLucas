# Documentação GeoLucas

**GeoLucas** é um projeto pessoal que trabalha com algumas bibliotecas matemáticas para criar um software matemático, inspirado no GeoGebra. Esse projeto conterá os principais conteúdos da área como funções, geometria 2D, geometria 3D, algebra, trigonometria, cálculo e outros conteúdos matemáticos.

## Funcionalidades

- Criação e manipulação de funções matemáticas.
- Geometria 2D: construção e análise de figuras geométricas.
- Geometria 3D: visualização e manipulação de sólidos.
- Álgebra: resolução de equações e operações algébricas.
- Trigonometria: cálculos e representações trigonométricas.
- Cálculo: derivadas, integrais e limites.
- Outras funcionalidades matemáticas diversas.
